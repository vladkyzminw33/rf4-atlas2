# Влад РР4 Атлас

Неофициальный справочник по Русской рыбалке 4: точки клёва с координатами, наживка, катушки, удилища,
готовые сборки, история водоёмов и подбор катушки под бюджет. Статический сайт без сборщика и зависимостей.

## Запуск

Нужен Node.js 20 или новее.

```
npm run serve     # http://localhost:8080
npm run check     # проверка данных и тесты
npm run build     # готовый сайт в dist/
```

Открывать `index.html` двойным щелчком нельзя: браузер не даст загрузить `data/*.json` с `file://`.

## Устройство

- `index.html`, `css/styles.css`: разметка и оформление (светлая и ночная темы, учитывается `prefers-reduced-motion`).
- `js/lib/`: чистая логика без DOM (форматирование, сортировка, фильтры, подбор катушки), покрыта тестами.
- `js/views/`: по одному модулю на раздел. `js/router.js`: вкладки по ARIA с управлением стрелками и `#hash`.
- `data/`: данные в JSON с источником у каждой записи. Описание: `docs/DATA.md`.
- `scripts/`: валидатор, импорт CSV/JSON, сборка, локальный сервер.
- `test/`: тесты на `node:test`.
- Политика безопасности контента (CSP) в `index.html` разрешает только свои скрипты и шрифты Google Fonts.

## Публикация

1. Создайте репозиторий на GitHub и загрузите проект в ветку `main`.
2. Settings → Pages → Source: GitHub Actions.
3. После каждого пуша `pages.yml` проверяет данные, гоняет тесты и выкладывает `dist/`.
4. Свой домен: Settings → Pages → Custom domain, затем CNAME-запись у регистратора на `<логин>.github.io`.

Подойдёт и Cloudflare Pages: команда сборки `npm run build`, папка `dist`.

## Автосбор из Telegram

Раз в сутки GitHub Actions читает публичные каналы из `data/channels.json` и открывает pull request с кандидатами в точки. На сайт они попадают только после вашей проверки. Подробности в `docs/DATA.md`.

## Данные и права

Данные внесены вручную из открытых справочников и постов игроков, источник указан в каждой карточке.
Автоматического парсинга чужих сайтов нет, см. `docs/DATA.md`. Проект не связан с разработчиками игры.
